## Development Focus

I build Java-based Minecraft server systems, backend integrations and supporting tooling. Most of my public work centers on Paper plugins, inventory workflows, economy systems, moderation tools and small service layers extracted from real server projects.

The main portfolio currently contains 51 Minecraft plugins with focused source excerpts and notes. Full private server code, deployment files and private infrastructure are not published.
